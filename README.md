# 🏎️ EchoPilot AI
### The AI Co-Driver That Listens Beyond Telemetry

EchoPilot AI is an AI-powered motorsport assistant that analyzes Formula-style driver radio communications to detect stress, fatigue, and emotions in real time. It combines speech recognition, emotion analysis, and lap-time data to provide engineers with actionable insights during a race.

---

## 🚀 Features

- 🎤 Upload driver radio audio (.wav/.mp3)
- 📝 Convert speech to text using AI
- 😊 Detect driver emotions (Calm, Stressed, Tired)
- 📊 Correlate emotions with lap times
- 📈 Interactive performance dashboard
- 📂 View previous analyses
- 📥 Export analysis reports

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Abhaspaul1234/EchoPilot-AI.git
```

Move into the project

```bash
cd EchoPilot-AI
```

Install backend dependencies

```bash
pip install -r backend/requirements.txt
```

Run the backend

```bash
python backend/app.py
```
